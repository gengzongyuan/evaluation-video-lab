# Langfuse 3 分钟微课

这组内容把 Langfuse 官方知识拆成从入门到深入的连续短视频。每集只回答一个问题，并保留可运行演示、官方来源和证据边界。

## 路径

1. 安装与概念
2. Trace / Span / Generation
3. Prompt 与数据集
4. Evaluation / Experiments
5. Scores、成本与延迟
6. 生产监控与治理

## 生产规则

- 官方文档是产品行为的首要依据；版本变化必须记录检索日期和文档 URL。
- 每集必须有一个可复现实验或界面动作；只有概念时明确标注“概念演示”。
- 不把未运行的 API 调用写成已验证结果；不把示意数据写成 Langfuse 性能或模型结论。
- 每集成片目标约 180 秒，状态写入 `manifest.json` 或对应脚本元数据。

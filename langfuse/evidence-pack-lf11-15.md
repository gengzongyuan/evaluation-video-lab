# LF-11–15 证据包模板

| 集数 | 必须证据 | 放行门 | 阻塞条件 |
|---|---|---|---|
| LF-11 | 同 Dataset 的 v1/v2 run、逐 item 输出、失败分类、汇总 | 同条件、同评分规则、版本可追溯 | 样本或条件不一致 |
| LF-12 | 异常 Trace、根因分类、修复 commit、回归 run、告警记录 | 修复前后可对照，失败样本保留 | 只有 Dashboard 截图 |
| LF-13 | Web/Worker/DB/对象存储 health、版本、重启恢复记录 | 组件状态与版本均可回指 | 只验证页面可开 |
| LF-14 | server/SDK/CLI/runtime 版本、lockfile hash、文档日期 | 代码、运行物和脚本一致 | 使用 latest 或版本未知 |
| LF-15 | 脚本、成片、原始素材、脱敏报告、manifest、回滚 commit | 每条断言有来源/运行证据，用户测试通过 | 缺证据、泄密或无法回滚 |

## 统一状态

- `prototype/L1`：可播放或可讲，但没有当前实例完整证据。
- `verified/L2`：固定条件下真实多样本/回读证据齐全。
- `ready`：画面、字幕、脱敏、版本、回滚和复述测试均通过。
- `blocked`：缺 Key、Trace/Run 不对应、字段未核对或存在敏感信息。

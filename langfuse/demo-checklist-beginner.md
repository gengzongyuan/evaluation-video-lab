# Langfuse 入门演示检查单

用于第 1–3 集录屏前检查，不替代官方文档。运行前记录 Langfuse 部署版本、SDK 版本、Git commit、运行日期和官方文档 URL。

## 环境

- [ ] Langfuse 实例可访问，已确认 workspace/project。
- [ ] 使用专用测试 project，不使用生产真实用户数据。
- [ ] `LANGFUSE_PUBLIC_KEY`、`LANGFUSE_SECRET_KEY`、`LANGFUSE_HOST` 通过本地环境变量注入。
- [ ] 屏幕录制前关闭终端历史、浏览器密码管理器和其他项目窗口。
- [ ] 录屏角标写明版本与日期；若 UI 与文档不同，暂停并记录差异。

## 第 1 集：最小可观测链路

1. 启动官方 SDK quickstart 或项目内等价示例。
2. 发送一条无敏感信息的固定输入，例如 `请把 2 加 3，回答一个数字`。
3. 等待 SDK flush/结束机制完成，再在 UI 按时间或 Trace ID 搜索。
4. 录下 input、output、时间和状态；不要录 secret key。
5. 在画面上标注“这只证明事件被记录，不证明回答质量”。

**通过条件**：Trace 可找到，输入输出与本地运行记录一致，且没有泄露密钥或个人信息。

## 第 2 集：Trace 调用树

1. 构造一个最小流程：用户输入 → 检索/普通函数 → 模型调用。
2. 依照当前 SDK 文档建立父 Trace 与子 Observation。
3. 故意制造一个可控的输入缺失或工具失败，记录错误节点。
4. 在 UI 展开父子关系，依次显示总耗时、失败节点、节点输入输出。
5. 清理错误堆栈中的密钥、路径和内部 URL。

**通过条件**：观众能从 Trace 找到失败节点，并能看到父子层级；视频不把单条 Trace 夸大为稳定性证明。

## 第 3 集：Span 与 Generation

1. 把检索、解析或工具函数按当前 SDK 示例记为 Span。
2. 把模型请求按当前 SDK 示例记为 Generation。
3. 对比两种节点的开始/结束时间和可用元数据。
4. 如果 token、成本或模型字段缺失，展示“字段取决于 SDK/供应商配置”。
5. 让模型调用失败一次，确认父 Trace 的结束与错误定位策略。

**通过条件**：Span/Generation 概念与实际代码一致；所有具体方法名在画面标出 SDK 版本；不把字段缺失解释成产品没有能力。

## 录屏证据包

每集至少保存：

- `run-command.txt`：实际运行命令（去除密钥）
- `input.json`：脱敏输入
- `output.json`：原始输出或错误
- `trace-id.txt`：Trace/Observation 标识
- `screenshot.png`：UI 关键状态
- `environment.md`：Langfuse/SDK/模型版本、日期、配置说明
- `claim-review.md`：口播主张与官方来源对应表

## 放行规则

- 有任何未运行的代码，字幕必须写“示例代码”。
- 有任何未确认的字段，口播改为“当前实例显示/取决于配置”。
- 没有原始输入输出，证据等级最多 L0/L1。
- 录屏完成后，让不了解背景的人只看前 30 秒复述本集问题；复述不对则回改钩子。

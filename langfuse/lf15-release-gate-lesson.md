# LF-15｜Langfuse 视频与实验发布门禁

## 一句话结果
看完后，观众能在发布前检查证据等级、脱敏、版本追溯、回滚和 blocked 条件。

## 发布门

- 每个具体断言能回指官方页面或实例运行记录。
- 视频里的输入、输出、Trace ID、截图和日志已脱敏。
- 版本、日期、SDK、服务端和实验 commit 已记录。
- 结论与证据等级匹配：概念为 L0/L1，多样本回读后才升级。
- 失败、缺字段或旧 Trace 不被剪成成功案例；保留 BLOCKED/FAIL 原因。
- 成片、原始素材、脚本和 manifest 版本一致，可回滚。

## 边界

发布门是质量控制，不是产品正确性的自动证明；必须由实际运行证据决定状态。

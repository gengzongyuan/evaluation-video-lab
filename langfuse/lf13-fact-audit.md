# LF-13 事实与来源审计：自托管架构与健康检查

核对范围：`lf13-self-hosting-lesson.md`、`evidence/lf13-15-recording-form.md`、`evidence-pack-lf11-15.md`，以及录制时引用的 Langfuse 官方自托管与部署文档。本文把“官方能力说明”“课程方法”和“当前实例观察”分开，避免把健康端点误说成全链路验收。

## 可以安全讲述的范围

| 主题 | 可安全讲述 | 不能由此推出 |
|---|---|---|
| 组件职责 | Web/UI 负责请求和界面；Worker 负责异步任务；PostgreSQL/ClickHouse、Redis、对象存储分别承担关系/分析数据、队列或缓存、文件对象等职责（具体版本以官方部署文档为准） | 某一组件在当前实例一定健康，或所有部署拓扑都相同 |
| health/readiness | health 端点可作为“进程/服务是否响应”的快速信号；readiness 可作为依赖就绪检查的入口 | health 200 证明 SDK 写入、Worker 消费、数据库持久化、对象存储或公网安全均正常 |
| 版本与部署 | 固定 server、镜像 digest、SDK/runtime 版本，并记录部署变更，有助于复现和回滚 | `latest`、一次页面打开或一个版本号能证明升级无回归 |
| 备份与恢复 | 备份策略应覆盖实际持久化组件，并通过恢复演练记录可回指 | 配置了备份就等于能恢复；未演练不能声称 RPO/RTO 达标 |
| 运行证据 | 组件状态、版本、重启恢复、备份恢复和原始响应应保存到同一证据包 | 历史截图、示意调用树或单次成功请求可代表当前生产状态 |

## 当前实例与阻塞边界

- 已记录实例版本为 Langfuse `4.79.0`，Web health/readiness 在核验时间点返回通过；这只说明对应端点当时可访问/响应。
- 当前安全环境没有可用于写入和回读的受保护项目 key；没有完成 Web、Worker、数据库、队列、对象存储的同条件全链路写入、消费、回读和重启恢复验证。
- 因此 SDK Trace 写入、Worker 消费、对象存储可用性、备份恢复、权限配置、生产安全和公网暴露状态均为 `BLOCKED` 或 `needs-review`；课程状态保持 `prototype / L1`。
- 视频与字幕不得出现内网地址、项目 key、secret、`Authorization`、登录信息、PII 或可复用的完整请求头。实例版本和状态应标注核验日期与环境范围。

## 最小证据包

1. 录制时间、环境标识（脱敏）、server/SDK/runtime 版本、部署 commit 或镜像 digest。
2. Web、Worker、数据库、队列、对象存储各自的 health/readiness 原始响应及命令/端点；保留 HTTP 状态、时间戳和 SHA-256。
3. 一次可回指的最小写入→异步消费→持久化→回读链路，包含 Trace/任务/对象 ID；没有项目 key 时写明 `BLOCKED`，不得用占位 ID。
4. 重启前后组件状态、恢复时间和依赖顺序；失败时记录日志摘要和回滚动作。
5. 备份文件清单、加密/权限检查、隔离环境恢复演练、恢复结果和 RPO/RTO 观察值；缺失字段写 `unknown`。
6. 逐条 claim review、脱敏检查、原始文件 SHA-256 清单和可复现脚本；把官方文档声明与实例观察分栏。

## 录制与发布门

- 画面可以使用示意拓扑：`Web/UI → API → Worker → DB/ClickHouse + Redis + Object Storage`，并在每个镜头明确标注 `prototype / L1`。
- 可以展示健康检查的判断顺序：先看进程响应，再看依赖就绪，再做受保护的写入/消费/回读和恢复演练。
- 只有所有组件在同一环境可回指、版本固定、写入和回读成功、重启与备份恢复证据齐全，才可升级为 `verified / L2`；当前不得使用“全链路通过”“已验收”“生产安全”等表述。

## 来源与复核

- 官方自托管入口：<https://langfuse.com/self-hosting>
- 官方部署文档：<https://langfuse.com/docs/deployment>
- 录制当天重新核对页面内容、组件名称、端点路径和当前 server/SDK 版本；页面 HTTP 200 只证明页面可访问，不证明实例行为。
- 运行证据应引用 `langfuse/evidence/` 下的原始记录，并注明采样时间、环境和脱敏状态；不得用旧截图替代当前核验。

## 审计结论

LF-13 可作为自托管架构和健康检查的方法课程，媒体与字幕按 `prototype / L1` 发布。当前实例仅有有限的端点与版本观察；组件全链路、写入/消费/回读、重启恢复和备份恢复均未形成完整可回指证据，保持 `BLOCKED`，不能声称当前部署已验收。

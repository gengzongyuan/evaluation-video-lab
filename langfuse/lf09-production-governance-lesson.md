# LF-09｜Sampling、脱敏、保留和生产治理

## 一句话结果
看完后，观众能在上线前检查观测成本、敏感数据、保留周期、权限和异常告警，而不是只看 Trace 数量。

## 3 分钟结构

- 0–30s：生产观测越多不一定越好，可能暴露隐私或拖高成本。
- 30–85s：解释 sampling 如何影响可见性与费用；采样规则要和关键错误监控配套。
- 85–130s：展示 input/output 脱敏、数据保留、项目权限和密钥轮换清单。
- 130–165s：异常告警要能回到 Trace、版本和失败样本；不要只报一个总量。
- 165–180s：发布门：先小流量验证，再观察错误率、延迟、成本和数据泄露。

## 证据边界

官方安全和采样文档证明配置能力，不证明你的部署已经安全。当前实例使用 HTTP 内网地址，不能在公开视频中暴露；正式上线门禁需单独核对 TLS、权限、保留和脱敏运行证据。

# V02｜两条 3 分钟评测科普脚本

## 使用边界

这两条是“可拍摄脚本”，不是已经完成的视频。脚本中的数字、模型名、效果结论必须在拍摄前替换成项目自己的实测证据；没有数据就用“待填实测”占位，不能口播成结论。

## 视频 01：为什么模型排行榜会骗人？

**一句话结果**：看完后，观众能用“三问法”判断一个评测榜单是否值得相信：测了什么、怎么测、差异是否超过误差。

**目标观众**：经常看到“模型第一名”“准确率提升 xx%”但不知道如何判断的产品、研发、测试和普通 AI 用户。

**封面标题**：模型第一名，真的最强吗？

**总时长**：约 170 秒；竖屏 9:16；一人出镜 + 大字卡 + 简单图表。

### 时间轴

| 时间 | 口播 | 画面 / 字幕 |
|---|---|---|
| 0–8s | “你看到一个模型登上第一名，先别急着换模型。排行榜最容易把‘测出来的第一’误读成‘所有场景都第一’。” | 画面先显示“NO.1”，随后裂成三个问号。字幕：`第一名 ≠ 所有场景最强`。 |
| 8–25s | “第一个问题：它到底测了什么？是知识问答、代码、长文本，还是工具调用？不同任务，冠军可能完全不同。” | 四张卡片依次出现：问答 / 代码 / 长文 / 工具；用同一模型在不同卡片上换位置。 |
| 25–55s | “第二个问题：它是怎么测的？同样叫‘准确率’，可能一个用公开题库，一个用私有题集；一个只跑一次，一个跑三次取平均。口径不一样，数字就不能直接横比。” | 左右对照：公开题库 vs 私有题集；单次 vs 三次平均。字幕：`先对齐口径，再比较数字`。 |
| 55–85s | “第三个问题：差异有没有超过误差？如果 A 是 81 分，B 是 80 分，但每次波动能到 2 分，那这个第一名可能只是抽样运气。” | 动画：A 81、B 80；误差带 ±2；两条线重叠。字幕：`差 1 分，不等于真的赢`。 |
| 85–115s | “一个靠谱的评测，至少应该让你看到：任务范围、样本数量、评分规则、重复次数和原始结果。只给一张排名图，不给这些信息，就只能当线索，不能当结论。” | 清单打勾：任务 / 样本 / 规则 / 重复 / 原始结果；最后把“排名图”标为“线索”。 |
| 115–145s | “你可以把这套方法记成三问：测什么？怎么测？差异稳不稳？下次看到‘全面领先’，先把这三个问题问完。” | 三问法做成可截图卡片，逐项出现。 |
| 145–170s | “如果你愿意，我下一条视频讲：为什么同一个模型，换个提示词就能从冠军变成普通选手。评论区留下你见过的排行榜，我用三问法帮你拆。” | CTA：`评论区丢一个榜单`；片尾固定角标：`评测不是排名，是决策证据`。 |

**互动设计**：评论引导只征集榜单链接或截图；不承诺当场验证，也不把评论中的数字直接当证据。

**拍摄清单**：手机竖屏、三张大字卡、两组简单折线图、一个“证据清单”画面。图表数字全部用示意值，并在画面角标标注“示意”。

## 视频 02：一次评测为什么不够？

**一句话结果**：观众学会把“一次跑分”升级成能支持决策的最小评测：同一任务、多个样本、重复运行、记录失败。

**目标观众**：正在做模型选型、Prompt 对比或 Agent 测试，但常用单条样例下结论的人。

**封面标题**：只测一次，结论可能是假的

**总时长**：约 175 秒；竖屏 9:16；桌面录屏 + 手写板书。

### 时间轴

| 时间 | 口播 | 画面 / 字幕 |
|---|---|---|
| 0–10s | “如果你只拿一条问题测模型，然后说‘这个模型更好’，你测到的可能只是这一条问题。” | 屏幕只有一条问题，右侧出现巨大问号。字幕：`单条样例 ≠ 稳定能力`。 |
| 10–35s | “先看最常见的误区：A 模型第一次答得好，B 模型第一次答得差，于是我们宣布 A 胜出。但换一条题，顺序可能反过来。” | 两道题卡片，A/B 分数交换；用“示意数据”标签。 |
| 35–65s | “最小可用的改法不是立刻做几千题，而是先固定一个小闭环：至少一组同类任务、多个样本、统一评分规则，并把失败案例留下来。” | 画出四格：任务集 / 样本 / 评分 / 失败记录。 |
| 65–95s | “为什么要重复？因为生成式模型有随机性。同一问题跑两次，答案可能不同。你要看的不是一次最高分，而是平均表现和波动。” | 同一题三次结果：8、6、7；计算平均 7，波动范围 2。字幕：`平均值 + 波动`。 |
| 95–125s | “为什么要记录失败？因为平均分会把关键问题藏起来。比如总分 90，但十道题里有一道每次都把金额算错，这可能正好是你的业务红线。” | 总分 90 分旁边放一个红色失败案例；字幕：`平均分不能替你识别红线`。 |
| 125–150s | “做选型时，建议至少同时看三件事：总体分、波动、关键失败。三者一致，结论才有机会进入决策。” | 三个仪表盘：总分 / 波动 / 关键失败；中间汇聚成“决策”。 |
| 150–175s | “下次做评测，先别追求样本数量的漂亮，先把这四格跑通。下一条我们拆评分规则：为什么‘看起来像对’不等于真的得分。” | CTA：`收藏四格最小评测`；片尾统一口号。 |

**互动设计**：邀请观众留言“你现在评测最难记录哪一项：样本、评分、重复、失败？”用于下一轮选题统计；不把投票结果当质量证据。

**拍摄清单**：一张四格板书、一个示意分数表、一个失败案例卡。所有数值均为示意，发布前替换为可追溯的实测或明确保留为教学示例。

## 统一制作规则

1. 前 8–10 秒只讲一个冲突，不塞背景知识。
2. 每 20–30 秒必须出现一次可视化变化：卡片、数字、对照、清单或手写板书。
3. 每条只交付一个观众动作：视频 01 是“三问法”，视频 02 是“四格最小评测”。
4. 口播中凡是带数字、排名、提升、优于的句子，都要能回指到数据表或实验记录；否则改成示意或方法论表述。
5. 片尾固定资产：系列名、下一集预告、评论问题、证据边界提示。

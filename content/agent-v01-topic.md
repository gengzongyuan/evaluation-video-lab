# V01｜系列定位与首轮选题

## 结论

系列暂名：**《3分钟看懂一次评测》**。

核心承诺：每集只回答一个“看完能做决定”的评测问题，用一个可复核的证据链，把“模型说得像不像”转成“在什么条件下值得用”。目标不是教观众背评测术语，而是让观众在 3 分钟内学会识别一个常见误区，并拿到一个可执行的判断动作。

首轮建议面向三类人：

- AI 产品经理/业务负责人：需要判断模型或 Agent 是否适合上线。
- 测试/评测从业者：需要把专业方法讲给跨团队听。
- 对 AI 结果好奇但缺少实验习惯的普通用户：需要知道“一个高分到底说明什么”。

## 选题判断规则

每个选题进入脚本池前，至少满足四项：

1. 有一个日常可感知的误区或冲突，例如“答对一次是否代表稳定”。
2. 能在 3 分钟内展示最小实验，至少有输入、输出、比较标准。
3. 能落到一个决策动作：继续测试、换模型、加约束或暂缓上线。
4. 证据边界清楚：明确样本量、场景、模型版本、时间和不能外推的范围。

不进入首轮的题：需要内部数据才能证明、只有术语没有案例、必须长篇背景才能成立、未经测试就直接推荐供应商或产品。

## 首轮两条具体选题

### 视频 01｜《模型答对一次，为什么还不能上线？》

- 一句话结果：观众学会区分“单次答对”和“稳定可用”，并会用 5 条同类样本做最小复测。
- 核心冲突：演示里答对一次很有说服力，但上线风险来自波动、边界和失败后的处理。
- 最小实验：准备 5 条语义相近、难度递进的问题；记录每次答案是否满足同一验收标准；展示“1/1 正确”与“5/5 稳定”的差别。
- 决策价值：若结果不稳定，下一步是补样本与错误分类，而不是立刻换模型或宣布成功。
- 证据边界：5 条样本只能说明这组样本上的初步稳定性，不能代表全部用户、全部语言和未来版本。
- 可视化：左侧是“演示成功”的单个绿色勾，右侧是 5 格样本矩阵；中间用失败类型标签（事实错、格式错、拒答错、上下文漏读）。

### 视频 02｜《评测分数高，就一定更好用吗？》

- 一句话结果：观众学会把“总分”拆成任务维度，并知道什么时候平均分会掩盖关键失败。
- 核心冲突：两个模型总分接近，但一个在关键任务上失败；平均数把风险稀释了。
- 最小实验：构造 3 类任务（准确性、遵循格式、拒答/安全）；展示两个模型各维度得分和加权前后排名变化。
- 决策价值：先确定业务的关键任务与权重，再看分数；不要因为总分第一就直接采购或上线。
- 证据边界：权重来自这次业务目标；换一个业务，排序可能改变。数据量和打分人一致性需单独记录。
- 可视化：先出现一个“总分排行榜”，随后拆成三根柱子；关键任务用红框标记，显示“总分第一但关键项垫底”的反转。

## 系列化模板

每集固定五拍：

1. 0:00–0:15 反直觉钩子：给出一个观众容易相信的判断。
2. 0:15–0:45 场景：谁会因此做错什么决定。
3. 0:45–1:45 最小实验：输入、方法、结果，画面只保留关键数字。
4. 1:45–2:35 解释：为什么结果不能被过度外推，指出证据边界。
5. 2:35–3:00 决策卡：观众下一次可以照做的一步 + 下一集预告。

## 依据与风险

依据来自评测的基本可复核要求：结果必须能追溯到样本、标准和环境；平均分、单次演示和小样本都不能脱离上下文解读。本文件没有引用外部基准的具体数值，避免在没有实测数据时制造“权威结论”。

风险是：首轮如果只有概念，没有真实跑分，视频只能作为“方法演示稿”，不能宣称某模型更强。制作时应把示例结果标注为“演示数据”或替换为已记录的真实实验结果。

## 固定交接格式

- 结论：首轮先做“单次正确≠稳定可用”和“总分高≠业务更好”两条。
- 我的理解：视频的产品是决策动作，不是知识点堆积。
- 隐含假设：观众可接受简单表格/柱状图；每集可获得至少 5 条样本或一组已留存实验记录。
- 能证明的范围：可建立脚本结构和最小实验方法。
- 不能证明的范围：不能凭本策划断言任何具体模型/供应商排名。
- 与其他 agent 的冲突：待汇合脚本与视觉方案后核对术语、时长和证据口径。
- 需要冻结的字段：视频标题、核心问题、样本/任务维度、验收标准、证据边界、决策动作。
- 依据：可复核、可解释、面向决策的评测原则。
- 产物：`content/agent-v01-topic.md`。
- 验证：文件已写入；内容包含两条选题、最小实验、边界与风险。
- 风险/缺口：还缺真实实验数据、旁白稿、镜头级素材和发布平台适配。
- 未完成：未拍摄、未配音、未发布。

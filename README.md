## 使用方式

1. 先读对应脚本，再填写拍摄前事实核验单。
2. 没有真实实验数据时，所有数字保持“示意”标记，不口播为模型结论。
3. 使用五格证据卡：问题、样本、方法、结果、边界。
4. 完成字幕、录屏和 30 秒复述检查后，才进入剪辑或发布。

本仓库当前交付的是可拍摄/可剪辑的视频包，不宣称已经完成真实拍摄、配音或平台发布。
